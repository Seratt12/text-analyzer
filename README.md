# text-analyzer

HTTP-сервис на C++ (Drogon), который принимает текст и возвращает статистику по нему.

## Что делает

Сервис предоставляет два эндпоинта:

- `GET /status` — проверка работоспособности сервиса.
- `POST /analyze` — анализ текста и возврат статистики.

## Требования

- **CMake** 3.23 или новее
- **C++20**-совместимый компилятор (MSVC 2022, GCC 11+, Clang 14+)
- **vcpkg** с установленным `drogon`
- **Ninja** (опционально, но рекомендуется)

## Установка зависимостей

```bash
vcpkg install drogon
```
